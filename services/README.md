# Servicios (plantilla)

Este repositorio es una **base arquitectónica**. Los servicios no son obligatorios al inicio.

Puedes:
- Mantener esta carpeta vacía hasta que el proyecto requiera servicios reales.
- Crear nuevos servicios siguiendo los blueprints en docs/guide/service-blueprints.md.
- Eliminar cualquier ejemplo si no lo necesitas.
